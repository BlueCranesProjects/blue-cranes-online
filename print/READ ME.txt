Blue Cranes print program

1. Install SumatraPDF (free) from sumatrapdfreader.org.
2. Run "Install print program". It puts everything in C:\BlueCranes
   and a "Blue Cranes - Print now" file on the desktop.
3. Test: in Admin > Print run tick one job and click Make print files,
   then double-click "Blue Cranes - Print now" on the desktop.
4. When the test prints right, run "Switch on 6am print" in C:\BlueCranes.

Printer and paper trays: open C:\BlueCranes\bc-print.ps1 in Notepad and
change the settings at the top (printer name, white tray, blue tray,
both sides for the technician's copies).

Client's copies and certificates print on one side; technician's copies
(time card, time sheet, quote pages) print on both sides.
After an update: download the zip again and run Install print program again.
Daily logs: C:\BlueCranes\Logs. Printed files: C:\BlueCranes\Printed.
